# TAKE 60

**60秒遊ぶと、15秒のコメディムービーになる。**

編集できるオリジナル3Dアバターで遊ぶ、ブラウザー向けのコメディアクションゲームです。外部サービスや生成APIに依存せず、ゲーム内の出来事からショートリプレイを自動編集します。

## 3つの撮影現場

| ゲーム | 遊び方 | 名シーンの種 |
| --- | --- | --- |
| 爆走デリバリー | 荷物を最大5個まとめて青いポストに届ける | 荷崩れ、バナナ、暴走カート、空への配達 |
| キッチン・パニック | 食材をフライパンで弾いて大鍋に入れる | 巨大トマト、飛ぶ食材、割れる皿 |
| オフィス・ブレイク | 家具を壊して連鎖をつなぐ | コピー機の爆発、椅子、空中からの急降下 |

## 操作

スマートフォンでは左のスティックで移動、右のボタンでジャンプとアクション。横画面を推奨し、縦画面にも対応します。

| 操作 | キーボード |
| --- | --- |
| 移動 | WASD / 矢印キー |
| ジャンプ | Space |
| アクション | X / Enter |
| 一時停止 | Escape |

タブが隠れたときは自動で一時停止します。Pointer Eventsのキャンセルとキャプチャ喪失、画面回転でもスティックを解除します。

## キャストとムービー

- 肌5色、服7色、髪型5種類、髪6色、目4種類、めがね、体格、顔の大きさ、なまえを編集できます。
- 60秒の出来事から、時間が重ならず種類の偏りも抑えた5カットを選びます。
- 衝突の前振り、インパクトのスロー、落下とリアクション、静止オチを15秒にまとめます。
- コミック／シネマ／カオスのカメラと字幕スタイルを選べます。
- `.take60.json` は編集済みの位置・表情・元のアニメーション時刻を記録した再生ファイルです。再シミュレーションせず、同じ動きを再生します。
- 前回のムービーとキャストは端末内に保存します。動画はMediaRecorder対応ブラウザーでMP4またはWebMを書き出します。対応しない場合もリプレイファイルの保存・読み込みは利用できます。
- SNSへの投稿は、書き出した動画をユーザー自身で行えます。

## 開発

必要なのは静的ファイル配信のみです。`dist/` がそのまま公開用ディレクトリです。`file://` で開くとES modulesを読み込めないため、HTTPサーバーで配信してください。

```sh
python3 -m http.server 8080 --directory dist
npm test
npm run check
```

ビルド・npm install・APIキーは不要です。Three.js r160を`dist/lib/`に同梱しています。依存ライブラリのMITライセンスは`dist/lib/THREE-LICENSE.txt`を参照してください。

## 構成

`core.js`：60Hzのゲームと物理 / `visuals.js`：3Dキャストとジオラマ / `replay.js`：イベント選定・編集・検証 / `input.js`：マルチタッチ / `audio.js`：音楽と効果音 / `main.js`：画面遷移・保存・動画出力。

公開先のSitesは`.openai/hosting.json`の既存プロジェクトを再利用してください。

## 検証範囲

Node.jsで3ゲームの60秒完走、実際の得点条件、吹っ飛びからの復帰、15秒リプレイの往復保存、カット境界、全髪型の3D変換、複数ポインターのキャンセルを検証します。今回の初版ではブラウザーによる視覚QAおよびiPhone実機での動画書き出し検証は未実施です。
